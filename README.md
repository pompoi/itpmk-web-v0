# itpmk-web-v0 — static deploy

Static hosting target for the Isekai Tamagotchi Pokemon Mortal Kombat v0 web
build. Contents of this repo are produced by `pnpm --filter @itpmk/web build`
in the main game engine repo and pushed here for GitHub Pages distribution.

This is a deploy artifact, not source of truth. Do not edit files here by
hand — they will be overwritten by the next deploy.

Tracking issue: ISEA-189.
